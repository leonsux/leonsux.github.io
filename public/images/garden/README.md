# 数字花园视觉素材

- `workspace-480.webp`、`workspace-640.webp`、`workspace-960.webp`：2026-09-26 使用 ImageGen 生成的无人书桌氛围图，不代表作者真实工作环境。提示词主题：暖色傍晚窗光、木桌、笔记本电脑、相机、咖啡、远山，无人物、无标识、无可读文字。主图压缩为 4:3 WebP；首页明确标注占位性质。
- `mountains.webp`、`journey.webp`：从用户提供的 V3 HTML Demo 内嵌图片提取并压缩的氛围占位图；原始来源和使用许可尚未提供，正式发布前需替换为自有或授权素材。
- `project-*.svg`：本地原创概念插画，不是产品截图；可用真实截图替换，保持 640:400 的比例。
- `project-drift-rush.svg`：Drift Rush 专属海岸漂移概念插画，包含原创俯视赛车、弯道、轮胎痕迹和海岸元素；沿用森林绿、暖纸与橙色配色，不包含脚本或外部资源。
- `paper.svg`：本地低透明度静态纸纹，不包含脚本或外部资源。
- `og-cover.jpg`：以生成的书桌图和站点文字制作的 1200×630 社交分享图；替换主视觉后同步更新。

图片路径、尺寸、替代文字集中在 `src/data/media.ts`。真实照片替换时应更新相关说明，移除占位标记，并保留 480 / 640 / 960 像素响应式版本。项目封面路径集中在 `src/data/projects.ts`。
